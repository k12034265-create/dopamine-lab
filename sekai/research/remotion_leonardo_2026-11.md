# Leonardo Grigorio | Build & Ship with AI ＋ Remotion スキルの研究（2026-11-21）
KOHが共有：https://youtu.be/VuHq5nunZQU 「How people are generating videos with Claude Code (Remotion Skill)」(2026-01-22)

## チャンネル
- 登録者 約2.6〜2.9万。中身は「AIで作る・出す」系の開発者向け（Claude Code、n8n、モデル比較、自前ホスティング）。動画づくり専門ではない。
- 動画づくりに関係するのはこの回。Remotion（ReactでSVG/HTMLを動かし、Chromiumで1コマずつ撮ってffmpegでmp4にする仕組み）の公式スキルを Claude Code に入れ、プロンプトだけで YouTube 風の画面アニメ（スクロール・ボタンを押す動き）を作る実演。
- ※この回の文字起こしはMacの内蔵ブラウザがつながらず未読。概要・章立て・要約サイトと、Remotion公式スキル（github.com/remotion-dev/skills）の中身で補った。

## 仕組みは今の自前パイプラインとほぼ同じ
- 自前：Playwright＋SVG（kami.js）→ スクショ → ffmpeg。Remotion：React → Chromium スクショ → ffmpeg。速度も同程度。
- Remotion の強み：Studio（ブラウザで時間軸をつまんで確認・数値をいじれる）、部品（場面転換・手書き風の丸／下線・光漏れ・モーションブラー）、尺を秒ではなくフレームで管理。

## 取り入れられるもの（公式スキルのルールから）
1. **場面のつなぎ**：今は全場面が0.35秒の暗転でつながる（50回暗くなる）。Remotion は TransitionSeries でクロスフェード／スライドが基本。→ 章の中はクロスフェード、章の切れ目だけ暗転にする。
2. **動きのカーブ**：`Easing.bezier(0.16, 1, 0.3, 1)`（速く出てすっと止まる）を標準にする。拡大の動きは「知覚的スケール」で補正（大きくなるほど遅く見える問題）。
3. **手書き風の強調**（rough-notation）：キーワードに赤丸・下線・マーカーを手書きっぽく引く。葦の「赤丸」に近い。紙芝居に合う。
4. **動く物にモーションブラー**：スライドインする札や矢印が滑らかに見える。
5. **光漏れ（light leak）**：章の切れ目に一瞬だけ。※KOHは強い光が嫌い・ホワイトアウト禁止なので、使うならごく弱く。
6. **指示の出し方**：「長くして」ではなく、フレーム番号・秒で指定する（例：0〜30フレームでフェードイン）。確認は静止画（still --frame）で先に見る。→ 今の snap 運用と同じ。

## 乗り換えの判断
- 全面的に Remotion に移すのは今はしない（作り直しが大きい・効果は部品の追加で取れる）。
- 部品（1〜4）を kami.js に移植するのが安い。
- Remotion のライセンス：会社規模で有料になる条件あり。使う前に公式で確認。
